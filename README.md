# wallpaperrotator

Liste des fonds d'écran lus par l'application Android WallpaperRotator en mode « En ligne ».

- `wallpapers.json` : un lien par image (`url`), une vignette (`thumb`) et une catégorie (`tag` : motivation, oldmoney, classique).
- Les images ne sont pas stockées ici : la liste pointe vers leur adresse d'origine.

L'application relit cette liste régulièrement. Pour ajouter ou retirer des fonds d'écran, il suffit de modifier `wallpapers.json`.
